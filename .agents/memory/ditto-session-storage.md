---
name: Ditto session storage
description: تخزين جلسة Ditto ومفاتيح NIM في Supabase بدل ملف ditto_session.json
---

جلسة مركز Ditto تُحفظ في جدول `ditto_sessions`، والقيم الحساسة تُشفّر داخل التطبيق باستخدام `SESSION_SECRET` قبل حفظها. يوجد ترحيل انتقالي واحد للملف القديم بعد إنشاء الجدول، ثم يُحذف الملف ولا تتم الكتابة محليًا.

**Why:** ملف الجلسة المحلي لا يثبت مع التطبيق وقد يفقد مفاتيح الاستماع عند إعادة التشغيل أو تغيير البيئة، كما أن قاعدة البيانات توفر مصدرًا دائمًا للجلسة.

**How to apply:** شغّل `29_ditto_sessions.sql` في Supabase SQL Editor، ثم افتح مركز Ditto مرة واحدة لترحيل الجلسة القديمة. لا تغيّر `SESSION_SECRET` بعد تخزين الجلسة المشفّرة.
