---
name: WhatsApp AI queue
description: اتفاقية تبادل رسائل واتساب مع سيرفر الذكاء الاصطناعي الخارجي
---

الموقع لا يستدعي نموذج AI مباشرة. يسجل الرسائل الواردة في Supabase، والسيرفر الخارجي يحجزها ويكتب الرد، ثم الموقع يرسل الرد إلى واتساب.

**Why:** فصل نموذج الذكاء الاصطناعي عن خدمة واتساب يسمح بتغيير النموذج أو السيرفر الخارجي بدون وضع مفاتيح AI داخل التطبيق، ويمنع فقدان الرسائل أثناء انتظار الرد.

**How to apply:** حافظ على دورة الحالات `pending → processing → ready → sending → sent`، وسجّل الفشل في `failed`. شغّل migration `26_whatsapp_ai_requests.sql` في Supabase SQL Editor قبل اختبار الربط.
